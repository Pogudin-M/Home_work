# Проект "Домашняя работа"

## Описание: 
Проект написанный на языке PYTHON, с использованием сервиса GITHUB.

## Установка:
1. Клонируйте репозиторий:
   ```bash
   git clone git@github.com:Pogudin-M/Home_work.git
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd Home_work
   ```
3. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
